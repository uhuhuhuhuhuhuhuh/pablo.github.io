Bounded synthesis
Regex match generator
Infinity cannot be scanned. Instead, this generates example strings that satisfy a common regex subset and calculates the exact Corridor address of each generated file. Supported: literals, groups, |, classes/ranges, \d, \w, \s, ., ?, *, +, and {m,n}. Lookarounds, backreferences, and negated classes are intentionally unsupported.

      

    


    

      
Codec
Compatible with the original Babel mapping
The original project uses a 70-character alphabet and two characters per directory, so every level has 70² = 4,900 possible folders. The path is a bijective base-4,900 representation of a byte sequence represented in bijective base-256.
For exact search, Infinite Corridor converts your input bytes directly into that address. For browsing, it performs the inverse calculation and reconstructs the current directory's file. An empty file lives at the root.
Everything here executes as JavaScript in this browser tab. GitHub Pages only serves these static files. Selected files are read with the browser File API and are not uploaded by this application.
The original ESP32 project exposes the same idea through MTP. Infinite Corridor independently reimplements the mathematical mapping for a browser interface and does not emulate USB or MTP.
