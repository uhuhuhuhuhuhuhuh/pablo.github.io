Read the protocol inscription

IC2C: exact corpus-assisted chunks are stored as verified public byte-range references. The receiver fetches those ranges and verifies each chunk hash before use.

IC2: the self-contained fallback stores every required bit inside the descriptor using recipes, internal references, deltas, dictionary compression, ordinary compression, or raw literals.

Batch mode: each selected file is encoded independently. One failure cannot invalidate another file's successful link.

The token limit remains 1,500,000 characters. Large or incompressible objects can still fail when their exact novel information cannot fit and is not represented by public corpus references.
