Adaptive file size

There is no arbitrary source-file size ceiling. The practical limit is the final self-contained share token, currently capped at 1,500,000 characters. An incompressible file can fit only about 1.07 MiB of raw data, while a much larger text, JSON, CSV, log, or other highly compressible file can work if gzip reduces it enough. Very large source files may require substantial browser memory while the link is created.
